# MRA format

The RBF knows nothing about either game. Everything game-specific arrives through the MRA on four ioctl indices.
MRAs are generated by `scripts/mra/nb2_mra.py` from `scripts/mra/games/<set>.json` (MAME 0.289 metadata plus the
board description); do not edit them by hand.

| Index | Content | Core |
| --- | --- | --- |
| 3 | Check record (sent first) | `rtl/nb2/nb2_rom_check.sv` |
| 2 | Board record | `rtl/nb2/nb2_board_config.sv` |
| 1 | EEPROM power-on image (2 KiB of `FF`) + `<nvram index="1" size="2048"/>` | `nb1_nvram.sv`, `nb1_eeprom.sv` |
| 0 | ROM stream (`zip="<set>.zip\|namcoc75.zip"`) | `rtl/nb2/nb2_rom_loader.sv` |

The CPUs are held in reset for every download. Indices 3, 2 and 1 come before the ROM stream.

## Index 0: ROM stream

Every MAME region in MAME byte order, placed in a fixed window; the stream offset equals the physical address
(`rtl/nb2/nb2_mem_pkg.sv`). Offsets below `0x2000000` are SDRAM, the rest is the DDR3 sprite store.

| Region | MAME region | Window | Offset | Outfoxies | Mach Breakers |
| --- | --- | --- | --- | --- | --- |
| ROZ | `c169roz` | 8 MiB | `0x0000000` | rot0-2 (6 MiB) + fill | rot0-1 (4 MiB) + fill |
| CHR | `c123tmap` | 8 MiB | `0x0800000` | scr0 + fill | scr0-2 + fill |
| VOICE | `c352` (MAME `0x000000-0x3FFFFF`, `0x800000-0xBFFFFF`) | 8 MiB | `0x1000000` | voi0 + fill | voi0, fill, voi1, fill |
| SHAPE | `c123tmap:mask` | 2 MiB | `0x1800000` | shas | shas + fill |
| ROZMASK | `c169roz:mask` | 2 MiB | `0x1A00000` | shar | shar + fill |
| PROG | `maincpu` | 1 MiB | `0x1C00000` | mpru bytes 0-1, mprl bytes 2-3 | same |
| DATA | `data` | 1 MiB | `0x1D00000` | dat0, dat1, each 16-bit word byte-swapped | dat0 + fill |
| C75DATA | `c75data` | 512 KiB | `0x1E00000` | spr0 | spr0 |
| C75BIOS | `mcu:internal` | 16 KiB | `0x1E80000` | `c75.bin` | `c75.bin` |
| (filler) | | | `0x1E84000` | zeros | zeros |
| OBJ | `c355spr` (first 20 MiB) | 20 MiB | `0x2000000` | 5 x (objNl bytes 0-1, objNu bytes 2-3) | same |

The stream ends at `0x3400000` (54,525,952 bytes). The C352 sees the VOICE window at addresses {A23, A21..A0}:
MAME's region repeats each voice ROM at +`0x400000` (`ROM_RELOAD`), so dropping A22 loses nothing. `nb2_mra.py
validate --zip ... --mame-regions ...` proves every window equal to MAME's own region memory
(`scripts/mame/nb2_regions.lua` dumps).

## Index 3: check record

As NB-1, magic `"NB2C"`. Little-endian fields.

* Header, 32 bytes: `"NB2C"`, version = 1, entry count (up to 32), two zero bytes, expected index-0 stream length
  (u32), 20 zero bytes.
* Entry, 32 bytes: region id (u8), lanes (u8), two zero bytes, offset (u32, multiple of 4), length (u32, multiple of
  4), one CRC32 per lane (4 x u32), four zero bytes. Lanes 1, 2 or 4: byte k of a longword belongs to lane
  k * lanes / 4. Lanes `0x12`: one CRC over bytes 1, 0, 3, 2 of every longword (a `ROM_LOAD16_WORD_SWAP` file).

## Index 2: board record (NB2B v1)

32 bytes, little-endian:

| Byte | Field |
| --- | --- |
| 0-3 | `"NB2B"` |
| 4 | version = 1 |
| 5 | record length = 32 |
| 6-7 | 0 |
| 8 | KEYCUS mode: 0 = none (every word reads `$0000`), 1 = ID word + changing word |
| 9 | KEYCUS ID word index (0-15; address `$C00000 + 2 * index`) |
| 10-11 | KEYCUS ID value (C390 = `$0186`) |
| 12 | KEYCUS changing-word index |
| 13 | bank transforms: bit 0 C123 pixel tile bits 6/8 swapped, bit 1 C123 tile bank, bit 2 ROZ pixel tile bits 4/6 swapped, bit 3 sprite bank bitswap (6,4,3,1,2,0) |
| 14 | orientation (MAME ROT / 90) |
| 15 | 0 |
| 16-23 | hot work-RAM pages: bit n = 4 KiB page `$208000 + n * $1000` is kept in block RAM |
| 24-31 | 0 |

Outfoxies: `4E 42 32 42 01 20 00 00 01 01 86 01 02 0D 00 00 FF FF FF 00 00 60 01 01 00 ...` (C390 ID on word 1,
changing word 2; transforms of MAME's `outfxies` config; 28 hot pages). Mach Breakers: KEYCUS none, transforms `$02`
(`machbrkr` config), 12 hot pages.
